Änderungen eines Nutzers rückgängig machen

Macht alle Änderungen eines Nutzers in einem Zeitraum rückgängig - jeder betroffene Eintrag wird auf den Stand direkt vor dessen erster Änderung im Zeitraum zurückgesetzt, inklusive Löschungen. Änderungen anderer Nutzer im selben Zeitraum an denselben Einträgen gehen dabei ebenfalls verloren.

Karte auf Zeitpunkt zurücksetzen

Setzt die gesamte Karte auf den gewählten Zeitpunkt zurück - jeder Eintrag, der seither von irgendjemandem verändert wurde, wird auf seinen damaligen Stand zurückgesetzt (inklusive Löschungen und Neuanlagen). Sehr weitreichend - nur im Notfall verwenden.
