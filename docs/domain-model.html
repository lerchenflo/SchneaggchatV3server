Schneaggchat Domain Model

Server entities (MongoDB documents of SchneaggchatV3server) and how they relate. Standard fields (id, createdAt, updatedAt, updatedBy, deleted) are hidden in the boxes; “Show all fields” lists them. Messages sync by a per-collection version counter, users, groups, events and map entries by updatedAt. Scroll or pinch to zoom, drag empty space to move around. Drag boxes, click one to edit. Edits are kept as a draft in this browser until you use “Save to file”.
